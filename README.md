# 💰 Ask Your Budget

A simple Python-based personal budget analyzer that helps users understand their income, expenses, and remaining balance using a CSV dataset. The project uses Python and Pandas to analyze financial records and display a quick summary.

## 📌 Features

- Calculates total income
- Calculates total expenses
- Calculates remaining balance
- Reads financial data from a CSV file
- Simple and beginner-friendly Python code

## 🛠️ Technologies Used

- Python
- Pandas
- CSV Dataset

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/Ask-Your-Budget.git
   ```

2. Open the project folder.

3. Install Pandas:

   ```bash
   pip install pandas
   ```

4. Run the Python file:

   ```bash
   python user_budget_code.py
   ```

## 📊 How It Works

The program reads the CSV dataset using Pandas and separates income and expense records. It then calculates:

- **Total Income:** Sum of all income transactions.
- **Total Expenses:** Sum of all expense transactions.
- **Balance:** Total Income minus Total Expenses.

## 🎯 Purpose

This project was created to practice Python programming, CSV file handling, and basic data analysis using Pandas.
